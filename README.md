# FUERZA ESPECÍFICA DIEGO

Repositorio individual de fuerza para Diego.

## Base del sistema

Está construido siguiendo la lógica del módulo **AKC Fuerza FIG**:

**Semana/carga → día → ejercicio → video**

La fuente de datos es un único archivo:

`Fuerza_Especifica_Diego.xlsx`

La aplicación no guarda los ejercicios dentro de `app.js`. Para modificar el contenido en el futuro, basta con editar el Excel y volver a publicar el repositorio.

## Excel

Columnas:

- `Día`
- `Ejercicio`
- `Link`
- `Segmento`

No se incluyen series, repeticiones ni peso por ejercicio. La carga semanal se selecciona en la interfaz:

- ALTA · 3×8 · Peso máximo
- MEDIA · 3×10 · Peso medio
- BAJA · 3×12 · Peso bajo

## Identidad

La interfaz conserva la estética oscura/metálica de AKC y utiliza el logotipo AKC como identidad visual.
